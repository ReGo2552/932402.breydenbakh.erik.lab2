# ЛР№2. Базовые и продвинутые возможности CSS

Группа 932402, Брейденбах Эрик.

Вариант **2 - «Путешественник»** (липкая навигация, бежево-оранжевая гамма).

## Задание

Страница «О себе» из ЛР№1, оформленная через внешний `style.css`:

- 3 способа подключения стилей - внешний файл, inline, внутренний `<style>`.
- CSS-переменные в `:root` для цветов и шрифтов.
- Позиционирование: `static`, `relative`, `absolute` (+ `sticky` для навигации по варианту).
- Состояния элементов: `:hover`, `:active`, `:focus`, `:visited`.
- Контрастность текста не менее 4.5:1.
