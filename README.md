# ЛР№2. Базовые и продвинутые возможности CSS

Группа 932402, Брейденбах Эрик.

Вариант **2 - «Путешественник»** (липкая навигация, бежево-оранжевая гамма).

Страница «О себе» из ЛР№1, та же разметка, теперь оформленная через CSS.

## Что реализовано

**Три способа подключения стилей:**

- Внешний файл `style/style.css` - основной объём стилей.
- Внутренний `<style>` в `<head>` - колонки для секции «Проекты» (`column-count: 2`).
- Inline-стиль — `font-size: 16px` на кнопке отправки формы.

**CSS-переменные** в `:root` - `--color-main`/`--color-panel` (бежевый), `--color-accent`/`--color-accent-dark` (оранжевый), `--color-text`, `--font-base`.

**Позиционирование** - показаны все виды:

- `position: sticky` - навигационное меню, остаётся видимым при прокрутке.
- `position: relative` + `position: absolute` - `<aside>` как якорь для декоративной иконки-пина.
- `position: static` - явно прописан на заголовке секции «Проекты» (демонстрация значения по умолчанию).

**Состояния элементов** - `:hover` (подсветка ссылок + линия под ними через `::after`), `:active`, `:focus` (обводка на полях формы и кнопке), `:visited` (ссылки навигации), в правильном порядке LVHA.

**Контрастность** - пересчитана по формуле WCAG: акцентный оранжевый специально подобран (`#a8511f`, не более яркий `#d97742`), чтобы держать ≥4.5:1 и как цвет текста на бежевом фоне, и как фон под белым текстом.

## Файлы

- `index.html` - разметка (наследуется от ЛР№1).
- `style/style.css` - все стили.

## Как посмотреть

Открыть `index.html` в браузере - сборка не нужна.
